1. Executive Summary & Architecture

The OSFORH HRMS Portal is designed to streamline corporate human resource workflows, employee lifecycle management, attendance metrics, and departmental organization. Built with high performance and zero-cost scalable infrastructure in mind, it decouples the client user interface from the API and persistence layer.

3. Core System Modules & Features

3.1 Authentication & Security

  • Session Verification: Validates user credentials against the database with hashed password matching or fallback administrative profiles.
  • Token Management: Issues an authentication bearer token stored securely on client session storage to authorize ongoing requests.
  • Role-Based Access: Automatically configures UI navigation, actions, and permissions based on the active persona (e.g., HR Manager, Department Lead, Staff).

3.2 Executive Dashboard & Real-Time Metrics

  • KPI Overview: Instant counts of Total Active Employees, Department Breakdown, Daily Present Rates, and Pending Leave Requests.
  • Live API Integration: The /api/dashboard/metrics.php endpoint computes these live metrics directly via SQL aggregate queries.
  • Visual Analytics: Responsive charts rendering workforce trends, department distribution, and monthly attendance velocity.

3.3 Employee Directory & Lifecycle

  • Complete Roster: Filterable, searchable datatable of staff profiles with photos, titles, emails, departments, and employment status.
  • Employee Management: Add new hires, edit employee records, update organizational assignments, or remove profiles.
  • REST Endpoint: Powered by /api/employees/index.php supporting GET, POST, PUT, and DELETE actions.

3.4 Attendance & Work Hours Tracking

  • Daily Logs: Real-time tracking of employee check-in times, check-out status, and attendance anomalies (late arrivals, half-days).
  • Filtering: Filter by date range, department, and attendance classification.

3.5 Leave & Absence Management

  • Leave Requests: Employees submit vacation, sick leave, or personal time off.
  • Manager Approvals: Pending requests are surfaced directly on the dashboard and HR console for one-click approval or rejection.

3.6 Celebrations & Organizational Culture

  • Surfaces upcoming birthdays, company anniversaries, and milestones to foster corporate engagement and team camaraderie.

4. Technical Directory Structure

backend/config/ Backend database.php (PDO connection) and cors.php (Access-Control headers).
database/hrms_db.sql Data Store Complete relational SQL schema with pre-populated dummy enterprise data.
vercel.json Deployment Configures single-page application (SPA) rewrites to guarantee zero 404s on browser reloads.

5. How the Data Flows (Step-by-Step)

1
User Action: The user visits hrms-pink-six.vercel.app. Vercel delivers the pre-built React application from global edge nodes in under 200ms.
2
Sign-In Request: User enters credentials on the login screen. The app sends a POST request with JSON payload to http://osforh-hrms.42web.io/api/auth/login.php.
3
Authentication & Token: The PHP script queries the employees table, validates the password, generates a session token, and returns the user object.
4
Dashboard Loading: Once authorized, React calls /api/dashboard/metrics.php. The server queries the database and streams real-time counts into the dashboard cards and charts.

6. Maintenance & Future Updates
